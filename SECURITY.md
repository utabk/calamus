# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's **Report a vulnerability** button on the repository's Security tab to send a private report.

Include what you found, how to reproduce it, and the impact you see. You'll get an acknowledgement within a few days, and a fix or a plan before any public disclosure.

## Scope

Calamus runs your shell, git and language servers on your machine, and reads and writes the folders you open. Reports about the app reading or writing outside the folders you opened, running code you didn't ask it to, or rendering untrusted content unsafely (Markdown preview, hover docs) are especially valuable.
